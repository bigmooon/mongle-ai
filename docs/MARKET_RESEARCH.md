# 시장조사와 포지셔닝의 근거

README의 기획 논리는 사용자가 제공한 발표 슬라이드 5장, 프로젝트 기획서와 확인 가능한 외부 자료를 대조해 정리했다. 과거 조사를 2026년 현재의 시장 통계로 표현하지 않는다.

‘사용자는 계획보다 기록·루틴을 찾는다’는 표현은 계획 기능의 수요가 감소했다는 통계적 결론이 아니라, 기록·지속 관리의 가치를 강조하는 팀의 해석으로 풀었다. ‘완료가 체크에서 끝남 → 애착 부족 → 재방문 동기 저하’도 검증할 제품 가설로 명시했다.

그림은 제공된 발표 자료의 논지를 바탕으로 새로 작성한 저장소용 SVG다. 원본 화면·차트 이미지를 수정하거나 경쟁 제품에 임의의 정량 점수를 부여하지 않았다. 기획 자료 전체는 [Google Drive 산출물 폴더](https://drive.google.com/drive/folders/1Lfv49TDbilo4ivoSIpw4v8RDEnEw9quC)에서 확인할 수 있다. 이번에 제공된 다섯 캡처의 Drive 원본 파일 URL은 확인되지 않았으므로 특정 Drive 문서가 해당 발표본이라고 연결하지 않았다.
